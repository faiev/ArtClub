Art Club renderer benchmark

This compares the editor's current full-grid DOM strategy (one accessible div per pixel, populated through a document fragment) with the isolated Canvas 2D prototype. This is a local browser microbenchmark, not a claim about end-to-end editor latency.

The default run measures 32×32 through 512×512, with two warm-up passes and five measured samples per renderer. Add query parameters such as ?samples=7&warmup=2&max=256 to change the run. Save the raw JSON report with browser and machine details.
